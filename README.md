**Libraries & Tools**
- [Noto Serif](https://fonts.google.com/specimen/Noto+Serif) and
- [Cascadia Code](https://fonts.google.com/specimen/Cascadia+Code) (Google Fonts) — used throughout for typography
- [Font Awesome](https://fontawesome.com/) — social/brand icons in the Links window
- [Web3Forms](https://web3forms.com/) — powers the Contact Me form without needing a backend server
